An entry for the make.fun bounty "The One-Line Exit". The program writes a single original one-line resignation letter: the writer resigns, effective immediately, because the office plant has been promoted twice and they have not. It reads as a letter someone could actually send, carries a specific workplace voice, and lands its surprise in the final words.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset). Python 3.13, standard library only, no network access, deterministic: every run writes exactly the same bytes.
